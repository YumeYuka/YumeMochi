YumeMochi 是一套 Compose 组件库，为 Android 和 Desktop 提供可复用的自研组件

<GitHub.Repo repo="YumeYuka/YumeMochi" />

<Steps>
  <Step title="配置仓库">

YumeMochi 发布到 GitHub Packages，在使用库的项目 `settings.gradle.kts` 中添加仓库和读取凭据

```kotlin
dependencyResolutionManagement {
    repositories {
        google()
        mavenCentral()
        maven {
            url = uri("https://maven.pkg.github.com/YumeYuka/YumeMochi")
            credentials {
                username = providers.gradleProperty("gpr.user").orNull
                password = providers.gradleProperty("gpr.key").orNull
            }
        }
    }
}
```

在用户级 `%USERPROFILE%\.gradle\gradle.properties` 中提供凭据

```properties
gpr.user=YOUR_GITHUB_USERNAME
gpr.key=YOUR_GITHUB_TOKEN
```

**注意：** 令牌需要 GitHub Packages 的 `read:packages` 权限，<u>不要把令牌写入项目或提交到版本库</u>

  </Step>
  <Step title="添加依赖">

按项目类型添加同一个完整库，KMP 放在 `commonMain`，Android 与 Desktop 放在应用模块的依赖块

<CodeGroup>

```kotlin title="KMP"
commonMain.dependencies { implementation("moe.yumeyuka.yumemochi:yumemochi:0.1.0") }
```

```kotlin title="Android"
implementation("moe.yumeyuka.yumemochi:yumemochi:0.1.0")
```

```kotlin title="Desktop"
implementation("moe.yumeyuka.yumemochi:yumemochi:0.1.0")
```

</CodeGroup>

完整库会解析 Android 与 Windows Desktop 所需的 KMP variant。主题和自研组件会作为传递依赖提供；组件实现统一放在 `:components` 模块

  </Step>
  <Step title="提供主题">

将 `MochiTheme` 放在 Android、Desktop 或 KMP 共享 UI 的根部

```kotlin
@Composable
fun App() {
    MochiTheme {
        AppContent()
    }
}
```

  </Step>
</Steps>
